# EC20-CEFAG-TOOLS

EC20-CEFAG-TOOLS 是一个用于 Windows 的 Quectel EC20 CEFAG 电话 / 短信小工具。

它通过 EC20 的 AT 串口工作，支持托盘后台运行、自动连接、短信收发、拨号、来电提醒、通话记录、VoLTE 状态显示、MBN/APN 查看，以及基于 Windows 音频设备的通话音频桥接。

## 主要功能

- 自动寻找 EC20 的 `Quectel USB AT Port`。
- 优先识别真正的 AT 端口，减少误选 NMEA / DM / 其他串口。
- 支持手动选择 COM 口、刷新端口、连接和断开。
- 支持开机后台自启动，并常驻 Windows 托盘。
- 单实例运行：重复打开 exe 时不会新开一个后台进程，而是唤起已有主界面。
- 自动检测 EC20 拔插，端口丢失后会自动释放旧连接并重新寻找模块。
- 主界面显示连接可用状态、搜网状态、SIM 卡状态、信号强度和网络制式，例如 LTE / GSM。
- SIM 卡拔出后显示 `SIM卡不可用`；重新插卡后会自动探测并重新搜网。
- 支持手动重新搜网。
- 设置页显示当前 MBN 和固件版本。
- 支持查看 MBN/APN 信息，MBN 与 APN 分两列显示，并用颜色标出激活、未知和未激活状态。
- 支持查看 VoLTE 状态，并提供 VoLTE 开关。
- VoLTE 关闭时显示 `VoLTE关闭`；打开但未注册时显示 `VoLTE注册中`；可用时显示 `VoLTE可用`。
- SIM 卡不可用时隐藏 VoLTE 状态和开关，避免误读状态。

## 电话功能

- 支持拨号，地区号码可单独填写，例如 `+86`、`+852`。
- 短号码会直接拨出，例如 `10010` 不会自动加地区号码。
- 支持来电通知和来电弹窗。
- 来电弹窗显示号码、通话状态、通话时长和挂断按钮。
- 来电等待接听时显示 `等待接听`，不会提前开始计时。
- 拨号时显示 `呼叫中`，接通后显示 `已接通`。
- 弹窗关闭时会自动挂断当前通话。
- 通话记录保存在本机，支持刷新和删除选中记录。
- 电话页提供 `挂断所有通话`，会向模块发送挂断指令。

## 通话音频

- 支持 EC20 UAC 音频桥接。
- 通话接通后，可自动把 `麦克风 (AC Interface)` 的声音桥接到 Windows 默认播放设备。
- 电脑麦克风声音会桥接到 `扬声器 (AC Interface)`，用于回传到 EC20。
- Windows 默认播放设备变化后，下一次通话会跟随新的默认播放设备，例如插入耳机后走耳机。
- 设置页可开启或关闭 `通话音频桥接`。
- 设置页提供 `音频检查` 和 `声音设置` 按钮。

## 短信功能

- 支持发送短信。
- 支持读取 EC20 中的短信。
- 支持收到新短信后弹出 Windows 通知，并自动读取保存到本机。
- 短信页分为 `收到的短信` 和 `发送的短信`。
- 支持删除选中短信记录。
- 短信内容会保存到本机，重新打开工具后仍可查看。

## AT 信令

- AT 信令不占用主标签页，入口在 `设置` -> `AT信令`。
- AT 信令窗口支持查看实时 AT 日志。
- 支持手动输入并发送 AT 指令。
- 支持保存 AT 信令日志。
- 支持自动滚动开关，关闭后查看旧日志时不会被新日志拉到底部。
- AT 信令日志点击保存后会保存在程序 exe 所在目录。

## MBN/APN 信息

- 入口在 `设置` -> `MBN/APN信息`。
- 弹窗打开后会后台读取 MBN 和 APN，不阻塞主界面，尽量避免影响来电和短信监控。
- 左侧显示模块内的所有 MBN。
- 右侧显示当前 APN 配置。
- 状态颜色：
  - 绿色：激活。
  - 黄色：未知。
  - 灰色：未激活。

## 使用前准备

1. 安装 EC20 对应的 Windows 驱动。
2. 插入 EC20 模块和 SIM 卡。
3. 在设备管理器中确认存在 `Quectel USB AT Port`。
4. 如需通话音频，确认 Windows 中存在 `AC Interface` 麦克风和扬声器。
5. 建议在 Windows 声音设置中将 `AC Interface` 麦克风和扬声器设为默认通讯设备，普通默认设备可继续保留为原来的扬声器/麦克风。

## 构建

项目使用 .NET Framework 4.8 WinForms。

可以使用 Visual Studio 打开 `EC20-CEFAG-TOOLS.csproj` 构建，也可以运行：

```powershell
.\build.ps1
```

构建后的 exe 会输出到：

```text
bin\Release\EC20电话短信工具.exe
```

## 测试设备

本工具当前主要在以下设备上测试：

```text
型号：EC20-CEFAG-5121-SGNS
ATI 返回型号：Quectel EC20F
固件版本：EC20CEFAGR06A16M4G
```

测试网络环境主要围绕中国联通 SIM、CU MBN、`3gnet` 和 `ims` APN 进行。

## 数据保存位置

短信记录、通话记录和设置默认保存在当前 Windows 用户的本地应用数据目录：

```text
%LOCALAPPDATA%\EC20电话短信工具
```

可以在工具的 `设置` 里点击 `修改路径` 改为其他目录。自定义目录会写入注册表：

```text
HKEY_CURRENT_USER\Software\EC20PhoneTool
值名：DataDir
```

开机自启使用的注册表位置是：

```text
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
值名：EC20PhoneTool
```

## 已知限制

- 工具依赖 EC20 暴露出的 AT 串口和 UAC 音频设备。
- 不同固件、运营商、SIM 卡套餐、基站策略和网络制式可能影响语音、短信和注册状态。
- VoLTE 是否可用取决于固件、MBN、运营商、SIM 套餐和当前网络，工具只能配置常见 Quectel 相关项并显示模块回应。
- 通话状态主要依赖 `RING`、`+CLIP`、`+COLP`、`+CLCC`、`NO CARRIER` 等 AT 信令判断。
- EC20 的 UAC 音频质量受模块、驱动、采样率和运营商语音链路影响。
- 如果拔插 EC20 后端口短时间被 Windows 占用，工具会尝试自动释放旧连接并重新寻找端口。
